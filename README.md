# Alzikrayat (MERN Photo Sharing)

Photo-sharing app built with MongoDB, Express, React and Node.

## Features
- Register and login (bcrypt + JWT)
- Upload photos (multer), gallery, photo details
- Comments on photos
- Only the owner can delete a photo
- Joi validation

## Run locally
1. cd server, then npm install
2. Copy .env.example to .env and fill in the values
3. npm start (port 5000)
4. cd client, then npm install, then npm run dev (port 5173)
